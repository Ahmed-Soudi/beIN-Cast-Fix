`dobby-android-elf.patch` is a project-owned portability patch for the exact Dobby
commit in `dependencies.json`. Run `apply-dobby-patch.py vendor/dobby` after the
clean checkout and before CMake. The script verifies both upstream files' Git
blob hashes and performs `git apply --check` before modifying either file.
It also verifies the patched output hashes. Repeat builds accept only the exact
already-patched files; unexpected or partially changed files stop the build.

The pinned ARM64 closure bridge used Apple `@PAGE` and `@PAGEOFF` relocations on
every platform. Android ELF assembly uses a plain `adrp` symbol and the `:lo12:`
relocation for `add`. Apple keeps its original instructions. The operation still
loads and calls the same closure handler; no bridge function is removed.

The pinned compiler script also passed Apple's `-arch armv7` option to ARM32
Android assembly. For Android, the NDK toolchain already selects the target, so
only `-x assembler-with-cpp` is retained. Other platforms keep the original flags.

The other pinned ARM64 trampoline uses local literal-load labels and has no
Apple relocation suffixes. Both x64 assembly files are guarded by `__x86_64__`,
so their bodies are omitted in this project's ARM builds. ARM32 bridge and
trampoline code are generated by the upstream ARM assembler implementation.

Source inspection established these repairs; the GitHub NDK build verifies the
actual assembly and linking. The patch does not establish device runtime behavior.
